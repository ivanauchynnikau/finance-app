# ✅ Реализована функция двух кнопок

## 🎯 Что изменилось

Теперь в приложении **две кнопки** для быстрого добавления транзакций:

### 🔴 Кнопка "Минус (-)" 
- Цвет: Красный
- Действие: Открывает диалог добавления **РАСХОДА**
- Расположение: Слева

### 🟢 Кнопка "Плюс (+)"
- Цвет: Зеленый  
- Действие: Открывает диалог добавления **ДОХОДА**
- Расположение: Справа

## 📍 Где доступны кнопки

### 1. Главная страница (Dashboard)
- Две круглые кнопки справа вверху
- Красная (минус) и зеленая (плюс)
- Размер: 48x48px

### 2. Страница "Операции"
- Две квадратные кнопки с обводкой
- Более компактные, в стиле outline

## 🎨 Дизайн

**Главная (Dashboard):**
```
- Кнопка (минус): Круглая, красный фон (bg-red-500)
- Кнопка (плюс): Круглая, зеленый фон (bg-green-500)
```

**Операции (Transactions):**
```
- Кнопка (минус): Outline, красная обводка и текст
- Кнопка (плюс): Outline, зеленая обводка и текст
```

## 🔧 Технические детали

### Измененные файлы:

1. **src/pages/Dashboard.tsx**

### Код изменений:

```typescript
// Dashboard.tsx
const [defaultType, setDefaultType] = useState<'income' | 'expense'>('expense');

<Button 
  onClick={() => {
```

## 🎯 UX/UI преимущества

✅ **Интуитивно понятно:**
- Красный минус = расход (отнять деньги)
- Зеленый плюс = доход (добавить деньги)

✅ **Быстрее:**
- Нужный тип транзакции уже выбран
- Не нужно переключать вкладку в диалоге

✅ **Визуально приятно:**
- Контрастные цвета
- Понятные иконки
- Соответствует семантике операций

## 🧪 Как протестировать

1. Обновите страницу в браузере (F5)
2. На главной странице увидите две кнопки справа вверху
3. Нажмите красную (минус):
   - Откроется диалог
   - Вкладка "Расход" будет активна
4. Закройте диалог
5. Нажмите зеленую (плюс):
   - Откроется диалог
   - Вкладка "Доход" будет активна
6. То же самое на странице "Операции"
