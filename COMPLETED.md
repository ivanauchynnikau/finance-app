## ⚠️ Важно!

### Требования к Node.js

**Текущая версия в системе: Node.js 10.19.0**
**Требуется: Node.js 18+ для работы Vite**

Для запуска проекта необходимо обновить Node.js:

```bash
# Установка nvm (Node Version Manager)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Перезагрузите терминал, затем:
nvm install 18
nvm use 18
nvm alias default 18

# Проверка
node --version  # должно быть v18.x.x или выше
```

После обновления Node.js:

```bash
cd /home/ivan/work/finance-app
npm install
npm run dev
```

## 🎯 Что дальше?

1. **Обновите Node.js** (см. выше)
2. **Создайте проект в Supabase** и выполните SQL из `supabase-schema.sql`
3. **Настройте .env** файл с вашими ключами Supabase
4. **Запустите проект**: `npm run dev`
5. **Зарегистрируйтесь** и начните использовать приложение!
